
# SUNEO
### Smart User Navigation & Ear Output

SUNEO is an AI-powered accessibility assistant designed to help visually impaired individuals understand their surroundings through voice interaction.

## Project Structure

- backend/  - Python FastAPI backend
- firmware/ - ESP32-CAM firmware
- flutter_app/ - Flutter Android application

## Hardware

- AI Thinker ESP32-CAM
- VL53L0X distance sensor
- Push button
- Power supply
- Bluetooth earphones

## Software Stack

- Python / Flask
- Flutter / Dart
- ESP32 / Arduino C++
- AI vision and language models
